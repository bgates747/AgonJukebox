# Editable skin fonts

The Art Deco playlist now uses [Lat7 Terminus 6×12](terminus/README.md).
Neutrino remains the small-field font.

## Neutrino 5×8

The selected Art Deco body font is [neutrino_5x8.font](neutrino_5x8.font),
exported and visually approved by the Author. Its bitmap bytes are preserved.
Open that file, or its adjacent [editor metadata](neutrino_5x8.font.xml), in
`agon-utils/examples/font_editor`. The metadata describes the finished 5×8
cells with zero offsets and scaling, so opening and saving does not apply the
original TTF crop a second time.

The editable sources also live in this project:

1. [Original TTF](neutrino-source/neutrino.ttf), copied byte-for-byte from the
   font editor's Neutrino source directory.
2. [TTF export settings](neutrino-source/neutrino_5x8.export.xml), retaining
   point size 8, original 5×11 cells, top offset −3 and height adjustment −3.
   Open this XML in the editor to reproduce the bitmap from the vendored TTF.
3. [Glyph sheet](neutrino_5x8.png), an 80×128 monochrome image with all 256
   slots arranged in 16 columns, generated by the editor's existing reader.
4. [Provenance](neutrino-source/provenance.json), including source/payload
   hashes, the original saved XML, importer identity and verification results.

The editor requires `original_font_path` to resolve from its working directory.
Both XML files currently use absolute paths into this project. After relocating
the checkout, open the `.font` directly for bitmap editing; update the source
path in the export XML before regenerating from the TTF. No font asset is
required from the sibling checkout.

### Import and target geometry

Use the font editor's existing `config_manager.load_font_metadata_from_xml`,
`agon_font.read_font` and `agon_font.write_agon_font`; no separate converter is
needed. For TTF regeneration, load the export XML, then pass its
`original_font_path` and settings to `read_font`, as the editor's file-open
handler does. Passing the export XML directly to the recursive `read_font`
branch reapplies its nonzero crop settings.

The target asset remains a loose monochrome `.font`, under the existing font
exception to AGNB packaging. Graphics continue to use AGNB.

| Property | Value |
| --- | --- |
| Cell / cursor advance | 5×8 pixels / 5 pixels |
| Slots | 256, indexed by byte value |
| Storage | 8 bytes per glyph; 2,048 bytes total |
| Scanline | One byte, MSB first; visible pixels in bits 7–3; bits 2–0 zero |
| Text coverage | ASCII 32–126; space blank, all other printable characters populated |
| Browser row | 60 characters occupy 300 pixels |

Extended slots preserve the original export, including any source-font fallback
glyphs; they are not a promise of a complete extended character repertoire.
The rightmost cell column is blank throughout printable ASCII, providing the
spacing within the five-pixel advance.

The file has the same byte length as an 8×8 font. Importers must take width 5
and height 8 from the metadata instead of inferring width from payload size.
The Base runtime creates its two fonts as 8×8 and 8×14. The Art Deco test
profile creates this font as 5×8; its five-pixel advance and native glyphs
pass emulator pixel comparisons. The profile's corresponding font-creation
and layout inputs live in `src/ui/artdeco` and `src/asm/skin_assets.inc`.

Verification used the existing editor reader/writer: loading the bitmap and
its normalized XML, and regenerating from the vendored TTF with the saved
export settings, all reproduce the exact 2,048 bytes and all 10,240 cell pixels.

## Winamp heading

The separate [Winamp Base 5×6 heading](winamp-heading/README.md) contains A–Z

## Art Deco font concept

[Art Deco concept 01](art-deco-concept-01/README.md) preserves the generated
letterforms and the Author's thresholded source. Its aligned draft provides
a 1024×2048 black/white PNG, 64×128 ASCII cells, editable SVG and font-maker XML.
This is source art for review and editing, separate from the active fonts.

[Recoloring antialiased sheets](../../docs/font-coloring.md) documents
`recolor_font.py`: configurable foreground/background PNG variants in the
exact Agon64 palette, with metadata and no dithering or font-editor dependency.
