# ArtDeco Concept 02

The second candidate, named to distinguish it from `ArtDeco Concept`.
`ArtDeco_Concept_02_source.png` is an unchanged copy of the supplied artwork.

Open **ArtDeco_Concept_02_79x79.png** in the Agon font editor. Its XML supplies
a 16×16 grid, character slots 0–255, 79×79 source cells, white foreground and
black background. This is a full-resolution editing source; choose final cell
dimensions and raster settings in the editor. Exports use the `ArtDeco` name
and `Concept_02` variant, keeping the first candidate's filenames distinct.

The supplied 1254×1254 image has fractional 78.375-pixel pitches. `prepare.py`
splits at the nearest integer source boundaries and pads each cell to 79×79,
yielding a 1264×1264 atlas. No glyph pixels are resampled, thresholded or
recolored. All original pixels reconstruct exactly, and the canonical editor
PNG reader loads the prepared image without changing pixels. Existing glyph
shapes and ordering, including the supplied extended symbols, are preserved;
those symbols have not been independently checked against a code-page standard.

The original PNG is retained for further processing. The editor-ready PNG is
the source for subsequent editor recipes. `provenance.json` records the input,
hashes, boundaries and checks. The preparation script uses the existing
agon-utils font metadata writer and PNG reader. It refuses to overwrite the
prepared PNG or sidecar, protecting subsequent edits.

## Saved 6×12 candidate

The Author saved `ArtDeco_Concept_02_6x12.png` and its XML. The PNG is 96×192
with levels 0, 85, 170 and 255; the nested bitmap metadata describes its finished
6×12 cells. The top-level XML retains the original editing recipe. Runtime
preparation reads the finished PNG without applying that recipe again.

`color-01` contains normal and highlighted Agon64 variants generated by the
existing tool:

```bash
.venv/bin/python src/fonts/recolor_font.py \
  src/fonts/art-deco-concept-02/ArtDeco_Concept_02_6x12.png \
  --output src/fonts/art-deco-concept-02/color-01
```

The output directory must be new. Preserve any previous color export before
regenerating. Both variants retain four colors, with the established pale-yellow
on black and black on gold pairs. The skin builder packs ASCII 32–126 into AGNB
and uses the editor's existing writer for a separate monochrome metrics font.
