# Art Deco font concept 01

Generated with the built-in image transformer using the AGON JUKEBOX title
as its style reference. See prompt.txt for the exact request and
generation.json for measurements. fontsheet.png is the unchanged output.

The requested mask was white on black in a 16×16 ASCII atlas with only
printable ASCII populated. The output is 887×1774 rather than 1024×2048,
contains intermediate colors and does not meet the requested row placement.
Treat it as a letterform concept for review, not a loadable font or a
replacement for the working Lat7 playlist font. No automatic cleanup or
application/deployment change was made.

The Author subsequently supplied fontsheet_thresholded.png, a strictly
black/white 887×1774 image without rescaling. The reproducible vectorization
and grid-alignment draft is in [aligned-01](aligned-01/README.md): a 1024×2048
import sheet with 64×128 cells, editable vectors and font-maker metadata.
Both input images remain unchanged. The aligned draft awaits visual review.

The Author's finished 6×12 antialiased export is
ArtDeco_Concept_6x12.png, with source-recipe and bitmap metadata in its XML.
[color-01](color-01/README.md) contains normal/selected Agon64 variants and a
comparison preview, preserving all four coverage levels and the supplied files.
