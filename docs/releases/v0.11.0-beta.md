# AgonJukebox v0.11.0-beta

Playback now follows the entire open directory, rather than being confined to
its currently displayed page.

- **Directory-wide shuffle and random play:** shuffle and `r` select from all
  playable WAV files in the open directory. Directory entries are skipped;
  the selected song is avoided when alternatives exist. A sole song remains
  selectable, and empty or directory-only listings leave selection unchanged.
- **Sequential playback across pages:** finishing the last song on a page
  advances to the next playable song on following pages. Playback wraps only
  after reaching the end of the full listing, skipping directories along the way.
- The browser follows the selected song, updating its page, row and page count.
  Cursor navigation retains its existing page-local wrapping. These changes run
  at song transitions, outside the audio streaming hot loop.
- The application banner now identifies this version as `v0.11.0-beta`.

This is the unskinned WAV-only `dev` line. Skins-branch changes are not included.
The scan covers the current directory listing; it does not recursively enter
subdirectories. Existing directory storage and sorting limits are unchanged.

Validation: 328 deterministic native random-selection cases and 374 sequential
cases pass, including mixed entries, page boundaries, directory-only pages,
single-song/empty cases and 256-entry lists. The author also passed interactive
emulator review of both enhancements. New hardware qualification remains pending.

The attached `jukebox.bin` is a self-contained 27,957-byte executable with
its font and logo embedded, for standard upstream Console8 VDP firmware.
Place it in the SD card's `/bin` directory, change to your music directory and
run `jukebox`. No music files are included.
