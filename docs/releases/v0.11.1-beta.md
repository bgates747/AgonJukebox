# AgonJukebox v0.11.1-beta

The skinned player now has the directory-wide playlist features previously
introduced in Classic. With Loop and Shuffle off, playback advances across
pages and wraps to the first playable track after the last song. Press R to
pick a random song from any page. Shuffle uses the same directory-wide
selection when a song ends. The browser follows the selected track.

Confirmed on Console 8. The skinned player uses stock-compatible MOS and VDP
commands. The ZIP includes the executable, buildable source, runtime skins
and an example configuration.
