# AgonJukebox v0.11.1-beta

Fixed sequential playback in the skinned player. With Loop and Shuffle off,
playback advances across page boundaries, skips directory entries, and wraps
to the first playable track after the last song in the directory.

Confirmed on Console 8. The skinned player uses stock-compatible MOS and VDP
commands. The ZIP includes the executable, buildable source, runtime skins
and an example configuration.
