# Flat-color source test 01

Mode: built-in imagegen, style transfer from the preserved smooth master.
Authorized: 2026-09-10. One source-art test, then Author review before tracing.

Use case: style-transfer / ui-mockup.
Input image: the existing smooth Art Deco Agon Jukebox master, used as the composition and shape reference.

Regenerate this interface as a clean, high-resolution, flat-color 2D animation-cel illustration with bold, consistent dark outlines. Preserve the reference's overall composition, proportions, recognizable ornament shapes, paired side columns, stepped architectural borders, fan crowns, central title, file browser, now-playing panel, transport row, footer, ruby jewels and turquoise inserts. Keep the entire rectangular design visible, straight-on, with no perspective or surrounding room.

The purpose is to create easily segmented, closed color regions for subsequent vector tracing. A separate program will add the metallic gradients, rounded-column shading and beveled edges later. For THIS image, make every region a solid, uniform base color. Broad gold/brass frame faces should be flat golden ochre. The tall column faces should be flat pale cream, with explicit outlines separating the structural flutes. Turquoise inlays and ruby jewels should be flat solid shapes. Keep the recognizable facets as outlined shapes, not highlights. Use a small coherent palette of gold/ochre, pale cream, turquoise/teal, ruby red, and black or very dark navy.

Use smooth, deliberate geometric contours and thick continuous outlines that separate adjoining forms. Outlines should remain substantial when the image is later reduced to 512x384, roughly 1.5–2 final-screen pixels for main contours. Favor clear enclosed shapes and generous clean separations. Retain characteristic Art Deco corners and stepped moldings, smooth fan curves and bilateral balance. Simplify insignificant hairline decoration where necessary. Do not add extra decoration.

Keep the reference's text, sample rows, selected row, simple transport symbols and panel arrangement. Main title: "AGON JUKEBOX". Browser headers: "#", "FILE NAME", "TIME". Now-playing labels: "NOW PLAYING", "SAPPHIRE.WAV", "01:26 / 04:18". Footer: "/MUSIC", "10 FILES". Use clean, solid-color lettering. These are demonstration contents, not textures in the artwork.

Output one large, high-quality 4:3 landscape image, preferably 2048x1536 or the available native 4:3 size. This is a LARGE source master for later programmatic processing, not a low-resolution bitmap. Keep curves smooth and edges crisp; no faux pixelation.

Avoid gradients, bevel shading, metallic rendering, reflective shine, highlights, bloom, glow, cast shadows, ambient occlusion, soft airbrush shading, texture, grain, speckles, dithering, sketchy lines, pixel art, mosaic effects, repeated tiny decorative fragments, graphic equalizer, and watermarks. The intended result is a flat-color inked animation cel, not a glossy gold rendering.
